本文件夹用于实现browsemaster自动评测工作流，旨在运行一个run_browse.sh能把数据集中想测的问题都运行完且测出正确率

以下是要实现的文件：

run_batch.py merge.py eval.py summarize.py run_browse.sh

最终在

run_batch.py：

最终效果是：python playground/browse_master/scripts/run_batch.py --json playground/browse_master/test/browsecomp_decrypted.json --lines <ids> --run-dir <run_path> --workers <workers>
用于批量运行 python run.py --agent browse_master --config configs/browse_master/config.yaml --task <task description> --run-dir <task_path>
python run.py 输出的结果要保存在<task_path> / "solution.txt"
其中<task description>是 playground/browse_master/test/browsecomp_decrypted.json 第<ids>项的"question"
用 ThreadPoolExecutor 来并行运行<workers>个任务
而<task_path>赋值为 <run_path> / <task_xxxx> 其中xxxx即为当前id的四位数表示形式，前面不够就添0

merge.py：

最终效果是：python playground/browse_master/scripts/merge.py --json playground/browse_master/test/browsecomp_decrypted.json --run-dir <run_path> --output-dir <out_path> 
用于在<out_path>里生成一个新的jsonl文件 merge.jsonl，来记录每个任务的answer（标准答案） 和 solution（agent生成的答案） 

eval.py：

最终效果是 python playground/browse_master/scripts/eval.py --input <input_jsonl> --output <output_jsonl> --workers <workers>
这个文件的内容是复制<input_jsonl>到新文件<output_jsonl>（<input_jsonl>就是上面merge.jsonl那个文件），再给<output_jsonl>每一项都加一个score字段，用大模型来评判每一项answer和solution是否语意相同，若相同则score赋值为1，反之为0
评判时以任务为单位，不同任务之间并行，并发度为<workers>

summarize.py：

python playground/browse_master/scripts/summarize.py --jsonl <jsonl> --result <result_path>
这个文件的作用是统计<jsonl>里有多少项score为1，并算出它占总项数的百分比，记录在<result_path>中

run_browse.sh

这个脚本运行上述完整工作流，脚本不设命令行参数，所有参数通过宏定义来实现：

IDS
RUN_NAME
RUN_WORKERS
EVAL_WORKERS
DATA_JSON

运行的顺序以及每个python的命令行参数如下：

python playground/browse_master/scripts/run_batch.py --json DATA_JSON --lines IDS --run-dir run/RUN_NAME --workers RUN_WORKERS

python playground/browse_master/scripts/merge.py --json DATA_JSON --run-dir run/RUN_NAME --output-dir run/RUN_NAME/results 

python playground/browse_master/scripts/eval.py --input run/RUN_NAME/results/merge.jsonl --output run/RUN_NAME/results/eval.jsonl --workers EVAL_WORKERS

python playground/browse_master/scripts/summarize.py --jsonl run/RUN_NAME/results/eval.jsonl --result run/RUN_NAME/results/results.json

并且全程用log文件来记录运行到哪一步了，run_batch.py内部也要有运行了第几个任务的记录，也输出到这个log文件中，log文件的位置为run/RUN_NAME/workflow.log
